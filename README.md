# Churn-Analysis-Power-BI
This project is a Power BI dashboard focused on betting analytics and performance tracking. The dashboard transforms raw betting data into actionable insights through interactive visualizations, KPI monitoring, trend analysis, and customer behavior evaluation.

The purpose of this project is to demonstrate practical data analysis skills including:

Data cleaning and transformation
KPI reporting
Interactive dashboard design
Business performance analysis
Trend identification
Data storytelling using Power BI

# Business Objective
The goal of this dashboard is to analyze betting activity and identify patterns that can help improve:

Customer engagement
Revenue tracking
Betting performance monitoring
Risk analysis
Retention strategies
Decision-making through data visualization

# Key Features 
The dashboard includes:

KPI Cards
Revenue and betting trends
Customer activity tracking
Betting category analysis
Interactive slicers and filters
Time-based performance analysis
Visual comparisons and summaries
